🚀 Getting Started
Run in Google Colab
Open Google Colab.
Import a notebook from this repository using File → Open notebook → GitHub, or open the notebook directly from GitHub.
Select the notebook you want to explore.
Run the code cells and modify the code to conduct your own experiments.
Record your observations in Markdown cells.
Run Locally (Optional)

Ensure Python 3 is installed, then clone the repository:

Open the .ipynb notebook in Jupyter Notebook or Visual Studio Code.
